# Exploratory Data Analysis (EDA) on E-Commerce Dataset

## Project Overview
This project was completed as part of the DecodeLabs Data Analytics Program.

The objective was to analyze an e-commerce dataset and uncover patterns, trends, and insights through Exploratory Data Analysis (EDA).

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data Inspection
- Missing Value Analysis
- Duplicate Check
- Descriptive Statistics
- Product Analysis
- Payment Method Analysis
- Order Status Analysis
- Sales Trend Analysis
- Outlier Detection
- Correlation Analysis

## Key Findings
- Analyzed 1200 orders.
- Identified top-selling products.
- Observed sales growth trends.
- Detected high-value order outliers.
- Found strong correlation between Unit Price, Quantity, and Total Revenue.
